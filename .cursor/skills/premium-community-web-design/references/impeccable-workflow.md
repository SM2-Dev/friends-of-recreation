# Impeccable workflow

Impeccable is the execution-quality layer beneath the Friends of Recreation art direction. It detects generic patterns and helps improve hierarchy, layout, typography, responsiveness, accessibility, and polish. It does not own the brand direction.

## Setup awareness

Use the installed Impeccable instructions as authoritative for exact command names. Current installations commonly expose commands such as `/critique`, `/audit`, `/typeset`, `/layout`, `/adapt`, and `/polish`, sometimes through an Impeccable namespace.

If project hooks are intentionally enabled, confirm they are active using Impeccable's documented status or doctor command. Do not enable, replace, or force hook configuration without the user's authorization when it would alter repository settings.

Impeccable can use `PRODUCT.md` for product context and `DESIGN.md` for approved design-system values. Do not generate a definitive `DESIGN.md` until actual fonts, palette, type scale, and radius choices are known. Once approved, document those exact values so detector findings can distinguish deliberate brand choices from drift.

## New page or major redesign

1. Establish Friends of Recreation art direction first.
2. Implement one coherent composition.
3. Run a critique for hierarchy, focus, brand fit, cognitive load, and AI-patterns.
4. Run an audit for accessibility, responsiveness, performance, and technical quality.
5. Use focused layout, typesetting, or adaptation passes only where findings justify them.
6. Run polish after the large issues are resolved.
7. Apply the project-specific quality gate last.

## Existing page refinement

Start with critique and audit. Separate findings into:

- functional or accessibility defects
- hierarchy and comprehension
- typography and layout
- responsive behavior
- generic AI patterns
- optional embellishment

Fix defects and high-impact hierarchy issues first. Do not churn the whole page merely because a different design is possible.

## Resolving conflicts

Use this order:

1. Accessibility and correct behavior.
2. Approved brand assets and project brief.
3. Intentional page composition and content priority.
4. Impeccable refinement advice.

Record a narrow exception only when a flagged value or pattern is genuinely intentional and supported by the approved design system. Do not ignore broad rule categories to silence useful feedback.
